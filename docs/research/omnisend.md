# Omnisend research (28 Sep 2026, web search snippets only — vendor pages blocked)

- **Pricing:** Standard from $16/mo (email sends = 12× contacts); Pro from $59/mo, unlimited email, SMS needs Pro from 4 May 2026. Exact price at 46k not found (calculator). Billed on subscribers + non-subscribed contacts (unsubscribed excluded). https://support.omnisend.com/en/articles/3533018-omnisend-pricing-plans-2026
- **API creates automations:** `POST /api/automations` (header `Omnisend-Version: 2026-03-15`, scope `automations.write`, paid plan). Only example seen uses delay + webhook blocks; whether email steps with content, or edits, are supported is **unconfirmed**. https://api-docs.omnisend.com/docs/how-to-send-webhooks-from-automations
- **Official MCP** at mcp.omnisend.com/mcp (OAuth, per-area read/write). Docs say it can create draft campaigns and **automation workflows** (can also send/schedule → needs guardrail). https://api-docs.omnisend.com/reference/mcp-server-v2 · https://support.omnisend.com/en/articles/15096086-connect-omnisend-mcp-to-ai-tools
- **Design:** custom HTML block + HTML template import; **Universal Layouts** (Dec 2025) = reusable blocks updating everywhere; abandoned-products and recommender blocks; unique Shopify discount codes with expiry. https://support.omnisend.com/en/articles/12981369-use-universal-layouts-to-keep-email-content-consistent
- **Shopify:** viewed product, added to cart, started checkout, placed order, order fulfilled. "Delivered" needs a tracking app (AfterShip/17TRACK). Back in stock only via Omnisend's own form. Customer tags sync (~2 min); no tag-added trigger → segment enter/exit trigger or Shopify Flow. Collection splits: medium-low confidence.
- **Automation:** conditional + A/B splits, exit on order, re-entry control, single fixed-hour waits (store timezone), SMS quiet hours/frequency cap. Not found: cross-automation email frequency cap, per-message sender.
- **Weaknesses vs Klaviyo:** shallower segmentation, weaker complex flows and reporting, reliance on add-on apps.
